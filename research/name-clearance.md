# Name clearance check: creature-collector RPG (hobby-level, not legal advice)

Checked 2026-11-14 with web search plus direct Steam store searches. Trademark data comes from third-party aggregators (markinton.com, trademarkdir.com, justia, gleanmark) found through search. **I could not query USPTO TSDR/Trademark Search, EUIPO eSearch or the WIPO Global Brand Database directly** because they are JavaScript apps the fetch tool can't drive. "No trademark found" below means none showed up in aggregator or search results. It does not mean the register is clear. itch.io search pages also could not be fetched (they redirect to the homepage), so itch.io coverage relies on search-engine indexing. The Google Play and App Store checks were done the same way, through site-restricted web searches.

Verdicts: **CLEAR** = nothing blocking found. **RISKY** = no hard conflict, but soft risks. **REJECT** = meets at least one of the three rejection criteria.

## Concept-level flag (not a naming issue)

*Pokémon Pokopia* (2026, Switch 2) has a premise very close to this game's hook: restoring a withered, barren Kanto habitat by habitat so that Pokémon return. https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Pokopia. Names and messaging should avoid echoing its vocabulary ("habitat restoration", "Pokopia-like"). The raised-by-care growth system and the battle/RPG structure are what set this game apart.
