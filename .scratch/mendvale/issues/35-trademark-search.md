Type: task

## Question

The earlier name check (`research/name-clearance.md`) used web search and trademark aggregators, because the official registers are JavaScript apps an agent can't drive. The human checks the registers directly before release:
1. **USPTO** Trademark Search (tmsearch.uspto.gov): search `MENDVALE` and `VERDLING`, and similar marks, in Classes 9, 28 and 41.
2. **EUIPO** eSearch plus (euipo.europa.eu/eSearch): the same terms.
3. **WIPO** Global Brand Database (branddb.wipo.int): the same terms.
4. **Google Play** and the **App Store**: search both names.
5. Record each result here: no hits, or the conflicting mark with its number and class.

If a live mark in Class 9, 28 or 41 conflicts, reopen the naming decision in ticket 06.
